# Contributing

This is source-available software owned by Srijan Upadhyay (see [LICENSE](LICENSE)).

- **Issues are welcome:** bug reports, questions about the rules, and suggestions for new tests.
- **Pull requests only by prior agreement.** Open an issue first. Contributions are accepted only if you agree in writing that the Author may use and license them under any terms.
- **Permission requests:** open an issue titled "Permission request" (see the README).
- Never post real company or personal data in issues. Use fictional examples.
